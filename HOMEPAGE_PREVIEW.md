## 🎭 Animation Patterns

### 1. **Hero Book Float**
- Movement: Vertical 8px
- Duration: 4s infinite
- Easing: ease-in-out
- Creates: Gentle floating feel

### 2. **Glow Pulse**
- Scale: 1.0 → 1.2 → 1.0
- Opacity: 0.5 → 0.8 → 0.5
- Duration: 3s infinite
- Creates: Breathing glow effect

### 3. **Card Press**
- Scale: 1.0 → 0.98
- Duration: 0.3s
- Creates: Physical button feel

### 4. **Fade In Up**
- Opacity: 0 → 1
- Transform: translateY(20px) → 0
- Trigger: Scroll into view
- Creates: Content reveal

## 🎯 Visual Hierarchy

### Size Ordering (Largest to Smallest)

1. **Hero Card** - 30px radius, large padding, dominant visual
2. **Daily Worship** - 26px radius, centered content, peaceful
3. **Featured Hymns** - 24px radius, horizontal scroll, rich

## 📱 Mobile Optimization

### Touch Targets
- Minimum: 44px × 44px
- Comfortable: 56px × 56px
- Large CTA: 64px × 64px

### Horizontal Scrolls
```
• Snap points: Optional
• Smooth scroll: -webkit-overflow-scrolling: touch
• Hidden scrollbars: ::-webkit-scrollbar { display: none }
• Padding: 8px vertical for shadow space
• Gap: 12-16px between items
```

### Performance
- CSS animations only (no JS animation loops)
- Hardware acceleration: transform, opacity
- Lazy scroll animations: IntersectionObserver
- No heavy images: Emoji-based icons

## ✅ Quality Checklist

✅ **Visual Polish**
- Consistent border radius (rounded design system)
- Proper shadow elevation (depth hierarchy)
- Smooth gradients (no banding)
- Clean typography (readable sizes)
- Generous whitespace (not cramped)

✅ **Interactions**
- Smooth animations (60fps)
- Responsive feedback (press states)
- Natural easing (cubic-bezier)
- Appropriate timing (0.3s standard)
- No janky scrolls (optimized)

✅ **Accessibility**
- High contrast (WCAG AA+)
- Large touch targets (44px min)
- Clear focus states (visible)
- Semantic HTML (proper tags)
- Color-independent (icons+text)

✅ **Mobile First**
- Touch optimized (large targets)
- Gesture friendly (scroll, tap)
- Fast loading (<1s FCP)
- Small file size (<20KB)
- Works offline (no external deps)

✅ **Brand Consistency**
- Heavenly blue palette
- Peaceful animations
- Christian themes
- Modern execution
- Premium quality
