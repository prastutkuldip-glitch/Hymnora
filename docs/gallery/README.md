# Church Gallery files

Upload fellowship photos and videos into this folder.

## Photos
- Formats: `.jpg` / `.png`
- Keep each file under about 2 MB so the gallery loads fast on mobile data
- Example name: `photo1.jpg`

## Videos
- Format: `.mp4` (H.264) plays on every phone
- GitHub's web upload accepts up to **25 MB per file**
- Larger clips: upload to YouTube as *Unlisted* and send the link instead —
  the app plays those inline too

After uploading, send the file names so they can be listed in the gallery.
