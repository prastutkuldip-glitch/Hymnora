## 🎯 How to Use

### **Step-by-Step Guide:**

1. **Open the App**
   - Visit: https://prastutkuldip-glitch.github.io/Hymnora/bible.html
   - App loads with all 66 books organized

2. **Browse Books**
   - Scroll through Old Testament (📜) or New Testament (✝️)
   - Click any book card to open

3. **Select Chapter**
   - See all chapters in a grid
   - Click any chapter number to read

4. **Read Verses**
   - Beautifully formatted verses
   - Each verse has a blue circle number
   - Scroll through entire chapter

5. **Copy or Share**
   - Click 📋 Copy button - verse copied to clipboard
   - Click 📤 Share button - opens WhatsApp to share

6. **Search**
   - Type in search box: `John 3:16`
   - Press Enter
   - Instantly see the verse

7. **Navigate Back**
   - Click floating ← button (bottom-right)
   - Or use browser back button

## 🛠️ Technical Details

### **Technology Stack:**
- **Frontend:** Pure HTML, CSS, JavaScript
- **API:** bible-api.com (Free, no-key required)
- **Hosting:** GitHub Pages
- **Design:** Bubble Glassmorphism UI
- **Responsive:** Mobile-first design

### **API Integration:**
```javascript
// Fetch chapter from API
fetch(`https://bible-api.com/${book}+${chapter}?translation=kjv`)
  .then(response => response.json())
  .then(data => displayVerses(data.verses));
```

### **Browser Support:**
- ✅ Chrome (Recommended)
- ✅ Firefox
- ✅ Safari
- ✅ Edge
- ✅ Mobile browsers (iOS Safari, Chrome Mobile)
